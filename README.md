# Мир Самозанятых — Web + Mobile + Светлана

Единая платформа для самозанятых: веб-сайт, Flutter Android/iOS и единый backend.

## Состав

- `backend/` — backend API (будет перенесён из проверенной локальной версии)
- `web/` — web application
- `mobile/` — Flutter Android/iOS
- `svetlana/` — единый runtime 3D-аватара Светланы
- `.github/workflows/` — воспроизводимый CI/CD
- `docs/` — аудит, безопасность и release-документация

## Правило качества

Непроверенное не объявляется готовым. Каждая версия должна проходить статическую проверку, а runtime/build результаты должны быть явно отмечены как фактически выполненные.

## Текущий источник миграции

Миграция выполняется из локально сохранённой проверенной версии `mir-samozanyatykh + Svetlana v13`. Критические бинарные assets (включая GLB Светланы) переносятся отдельно с SHA-256 проверкой.
